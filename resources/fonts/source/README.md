Source fonts used by the notes style, matching the website typography.

- SourceSerifPro: https://github.com/adobe-fonts/source-serif/tree/3.001R
- SourceSansPro: https://github.com/adobe-fonts/source-sans/tree/2.045R-ro%2F1.095R-it
- SourceCodePro: https://github.com/adobe-fonts/source-code-pro/tree/2.042R-u%2F1.062R-i%2F1.026R-vf

Unmodified Adobe releases, distributed under the SIL Open Font License 1.1; see the accompanying license files.

The website build registers this directory with its TeXmacs profile. When using a different TeXmacs profile, import the fonts from this directory in the font selector. No system-wide font installation is needed.
